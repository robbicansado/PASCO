# FlexDuino V5 — recovered firmware archive

The local PASCO directory contains these artifacts:

- `flexduino_v5_backup.hex` — Intel HEX firmware backup (original local archive).
- `flexduino_v5_backup.bin` — binary firmware backup (original local archive).
- `flexduino_v5_disassembly.txt` — disassembly derived from firmware.
- `flexduino_v5_recuperado.ino` — **empty Arduino template only**; it is **not** recovered V5 source code.

**Provenance:** local PASCO ZIP supplied on 17 October 2026.

**Publication status:** the binary/HEX backups and disassembly are retained in the original local ZIP but **have not been uploaded in this commit**. They must be transferred without modification and checked with a hash before marking this recovery archive complete.

Never describe the disassembly as the original Arduino source code. Firmware restoration and compatibility with a particular board require separate verification.
